# Views

## Definição

Função ou classe responsável por receber uma requisição e devolver uma resposta. É a camada "Controller" no padrão [[MVC|MVC]]/MVT.

## Quando usar

Toda rota de uma aplicação Django passa por uma View, que decide o que fazer com a requisição (consultar um Model, validar dados, renderizar um Template ou um Serializer).
