# Serializers

## Definição

Componentes que convertem objetos complexos (como um Model do Django) em formatos simples como JSON, e validam dados de entrada antes de salvá-los. No DRF, é a peça central de qualquer endpoint.

## Quando usar

Sempre que uma [[REST API|REST API]] precisa transformar dados do banco em JSON (saída) ou validar JSON recebido (entrada).
