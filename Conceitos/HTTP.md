# HTTP

## Definição

Protocolo de comunicação cliente-servidor da web. Define métodos (`GET`, `POST`, `PUT`, `DELETE`...), status codes (`200`, `404`, `500`...) e headers.

## Quando usar

É a base de qualquer comunicação entre frontend e backend, inclusive em uma [[Conceitos/REST API|REST API]].
