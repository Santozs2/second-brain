# Git Flow

## Definição

Modelo de organização de branches no Git: `main` (produção), `develop` (integração), `feature/*` (novas funcionalidades), `release/*` e `hotfix/*`.

## Quando usar

Em projetos com mais de uma pessoa ou com ciclos de release bem definidos. Para projetos pessoais pequenos, um fluxo mais simples (`main` + `feature/*`) costuma bastar.
