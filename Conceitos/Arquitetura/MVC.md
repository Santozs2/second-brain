# MVC

## Definição

Model-View-Controller: padrão que separa uma aplicação em três camadas — dados (Model), apresentação (View) e lógica de controle (Controller). O Django usa uma variação chamada **MVT** (Model-View-Template), onde a "View" do Django faz o papel de Controller e o "Template" faz o papel de View tradicional.

## Quando usar

Para organizar aplicações web separando dados, lógica e apresentação, facilitando manutenção e testes.
