# Models

## Definição

Representação de uma entidade de dados (geralmente uma tabela) diretamente no código, no padrão [[Conceitos/MVC|MVC]]/MVT. No Django, cada Model vira uma tabela no banco através do [[Conceitos/ORM|ORM]].

## Quando usar

Para definir a estrutura de dados de uma aplicação — campos, tipos, relacionamentos e validações.
