# 💿 Disk I/O Management

---

## 🎯 Disk Scheduling

**FCFS:** Ordem chegada  
**SSTF:** Shortest seek time (starvation)  
**SCAN:** Cabeça vai ponta-ponta  
**C-SCAN:** Circular SCAN  

SCAN é prático!

---

## 📊 Tempo de Acesso

```
Seek time: 5-10ms (cabeça se move)
Rotational latency: 2-3ms
Transfer: <1ms
Total: ~7-14ms
```
