# 🛣️ Routing

---

## 🎯 Routing Table

```
Destino | Máscara | Gateway | Interface
10.0.0.0 | /8 | 192.168.1.1 | eth0
```

Packet vai para gateway que sabe próximo hop

---

## 📊 Algoritmos

**Dijkstra (OSPF):** Caminho mais curto  
**Bellman-Ford (RIP):** Distance vector
