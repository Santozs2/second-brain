# 🌐 TCP/IP Model

> 4-layer practical model.

---

## 🔢 4 Camadas

```
4. Application   - HTTP, DNS, FTP, SSH
3. Transport     - TCP, UDP
2. Internet      - IP, ICMP, IGMP
1. Link          - Ethernet, PPP
```

---

## 📊 Comparação OSI

```
OSI: 7 layers (teórico)
TCP/IP: 4 layers (prático)

Application Layer (TCP/IP) =
  Application + Presentation + Session (OSI)
```

---

## 🎯 IP Addresses

```
IPv4: 192.168.1.1 (32 bits, 4 octetos)
IPv6: 2001:db8::1 (128 bits, hexa)
```
