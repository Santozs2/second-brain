# ⚖️ Load Balancing

---

## 🎯 Estratégias

**Round Robin:** Ciclicamente  
**Least Connections:** Menos conexões ativas  
**IP Hash:** Mesmo IP → mesmo servidor  
**Weighted:** Alguns servidores mais rápidos  

---

## 📊 Hardware vs Software

**HAProxy, NGINX:** Software  
**F5, Citrix:** Hardware (mais rápido)
