# 🌐 Proxy & Reverse Proxy

---

## 🎯 Forward Proxy

Cliente → Proxy → Server  
Cliente acha que fala com proxy  
Esconde identidade do cliente

---

## 🎯 Reverse Proxy

Client → Reverse Proxy → Servidores  
Cliente acha que fala com server  
Load balancing, caching

---

## 📊 Usos

**Forward:** VPN, corporativo, filtro  
**Reverse:** Cache, load balancing, segurança
