# 🌐 Network Introduction

> Fundamentos de redes.

---

## 🎯 Tipos de Rede

**LAN:** Local Area Network (escritório)  
**WAN:** Wide Area Network (Internet)  
**MAN:** Metropolitan Area Network (cidade)  

---

## 🔌 Topologias

**Star:** Todos conectam em hub central  
**Bus:** Todos na mesma linha  
**Ring:** Forma um anel  
**Mesh:** Cada node conecta a todos  

---

## 📊 Bandwidth vs Latency

**Bandwidth:** Quantidade de dados (Mbps)  
**Latency:** Tempo para ir (ms)  

Ambos importantes!
