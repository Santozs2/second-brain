# 📐 Linear Algebra

> Vetores e matrizes.

---

## 📊 Vetores

```python
v = [1, 2, 3]

# Magnitude
|v| = sqrt(1² + 2² + 3²) = sqrt(14)

# Dot product
v·w = 1*4 + 2*5 + 3*6 = 32
```

---

## 📊 Matrizes

```python
A = [[1,2], [3,4]]

# Multiplicação
A*B = elemento a[i][j] = sum(A[i][k]*B[k][j])
```
