# CRUD

## Definição

Create, Read, Update, Delete — as quatro operações básicas sobre qualquer dado persistido.

## Quando usar

É o vocabulário básico para pensar em qualquer funcionalidade que manipula dados, seja em uma [[Conceitos/REST API|REST API]] ou direto no banco.

## Mapeamento comum

| Operação | HTTP | SQL |
|---|---|---|
| Create | `POST` | `INSERT` |
| Read | `GET` | `SELECT` |
| Update | `PUT`/`PATCH` | `UPDATE` |
| Delete | `DELETE` | `DELETE` |
