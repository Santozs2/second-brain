# Cache

## Definição

Armazenamento temporário de dados já processados, para evitar reprocessar ou reconsultar algo caro toda vez.

## Quando usar

Em respostas de [[Conceitos/HTTP|HTTP]]/API que mudam pouco, ou em consultas ao banco que se repetem muito.
