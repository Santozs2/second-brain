# Git

> [!tip] Status
> 🟢 Confortável

## 📝 Resumo

Git é o sistema de controle de versão usado para rastrear mudanças no código e colaborar em projetos (geralmente via GitHub).

## 🧠 Conceitos principais

- **Repositório**: `git init`, `git clone`
- **Commits**: `git add`, `git commit`
- **Branches**: `git branch`, `git checkout -b`, `git merge`
- **Remoto**: `git push`, `git pull`, `git fetch`
- **Resolução de conflitos**
- **`.gitignore`**

## 💻 Exemplos

```bash
git checkout -b feature/login
git add .
git commit -m "feat: adiciona tela de login"
git push origin feature/login
```
