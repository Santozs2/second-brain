# Linux

> [!tip] Status
> 🟡 Aprendendo

## 📝 Resumo

Linux é o sistema operacional mais usado em servidores. Saber usar o terminal é essencial para desenvolvimento web e DevOps.

## 🧠 Conceitos principais

- **Navegação**: `cd`, `ls`, `pwd`
- **Arquivos**: `cp`, `mv`, `rm`, `mkdir`, `touch`
- **Permissões**: `chmod`, `chown`
- **Processos**: `ps`, `kill`, `top`
- **Redirecionamento e pipes**: `>`, `>>`, `|`
- **Gerenciadores de pacotes**: `apt`, `dnf`

## 💻 Exemplos

```bash
# Listar arquivos com detalhes
ls -la

# Buscar texto dentro de arquivos
grep -r "TODO" ./src

# Dar permissão de execução
chmod +x deploy.sh
```
