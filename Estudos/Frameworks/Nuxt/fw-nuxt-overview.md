# 🎯 Nuxt - Vue Meta Framework

---

## 📊 Overview

**Type:** Meta framework for Vue  
**Features:** SSR, SSG, Auto-routing  
**Latest:** Nuxt 3  

---

## 🚀 Features

- **Auto file-based routing**
- **SSR/SSG/Hybrid out-of-box**
- **Middleware support**
- **Built-in state management**
- **Composables sharing**

---

## 📂 Project Structure

```
pages/
  index.vue      → /
  about.vue      → /about
  user/
    [id].vue     → /user/:id
components/
composables/
app.vue
nuxt.config.ts
```

---

## ⚡ Getting Started

```bash
npx nuxi init my-app
cd my-app
npm install
npm run dev
```
