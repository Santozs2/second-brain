# 🟢 Node.js - Modules

---

## 📦 CommonJS

```javascript
const fs = require('fs');
module.exports = { myFunction };
```

---

## 🔧 ES Modules

```javascript
import fs from 'fs';
export { myFunction };
```

---

## 🎯 Built-in Modules

- `fs` - File system
- `http` - HTTP server
- `path` - Path utilities
- `events` - Event emitter
- `stream` - Streaming
