# 💚 Vue - Complete Framework Guide

---

## 📊 Overview

**Type:** Progressive JavaScript framework  
**Creator:** Evan You  
**Versions:** Vue 2, Vue 3 (Composition API)  
**Market:** 20% of developers  

---

## 🎯 Features

- **Reactive data binding** - Automatic UI updates
- **Component-based** - Reusable UI pieces
- **Single-File Components** - HTML + CSS + JS
- **Vue Router** - Client-side routing
- **Pinia** - State management

---

## 🏗️ Project Structure

```
src/
  components/
  views/
  App.vue
  main.js
public/
vite.config.js
```

---

## 🚀 Vue 3 (Latest)

Composition API - more flexible, similar to React Hooks.

---

## 📦 Ecosystem

- **Vite** - Build tool
- **Vue Router** - Routing
- **Pinia** - State (Vuex replacement)
- **Axios/Fetch** - HTTP
