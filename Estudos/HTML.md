# HTML

> [!tip] Status
> 🟢 Confortável

## 📝 Resumo

HTML (HyperText Markup Language) é a linguagem de marcação usada para estruturar o conteúdo de páginas web. Define elementos como títulos, parágrafos, listas, formulários e mídia.

## 🧠 Conceitos principais

- **Elementos e tags**: `<tag>conteúdo</tag>`
- **Atributos**: `class`, `id`, `src`, `href`, `alt`
- **Semântica**: `<header>`, `<main>`, `<nav>`, `<section>`, `<article>`, `<footer>`
- **Formulários**: `<form>`, `<input>`, `<label>`, `<select>`, validação nativa
- **Acessibilidade**: uso correto de `alt`, `aria-*`, hierarquia de headings
- **Metadados**: `<head>`, `<meta>`, SEO básico

## 💻 Exemplos

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Minha página</title>
</head>
<body>
  <header>
    <h1>Olá, mundo</h1>
  </header>
  <main>
    <p>Conteúdo principal aqui.</p>
  </main>
</body>
</html>
```
